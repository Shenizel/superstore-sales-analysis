# Superstore Sales Analysis 🛒

## Overview
An end-to-end data analysis project examining sales, profit, 
and discount patterns of a retail superstore.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI (4-page interactive dashboard)

## Key Findings
- West region generates the highest sales ($725K)
- Technology is the most profitable category (17.4% margin)
- Furniture has high sales but only 2.5% profit margin
- Discounts above 40% consistently lead to losses
- Tables (-$17,725) and Bookcases (-$3,472) are loss-making sub-categories
- Consumer segment drives the highest revenue ($1.16M)

## Dataset
Sample Superstore Dataset from Kaggle
